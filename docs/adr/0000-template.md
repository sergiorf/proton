# ADR NNNN: Title in a few words

- **Status:** proposed | accepted | superseded by ADR NNNN
- **Date:** YYYY-MM-DD
- **Plan task:** M<milestone>.<n>, decision D<n> if any

## Context

The problem and the forces at play: what has to be decided, the constraints, and what is known
(measurements, prototypes, licenses). Facts, not the answer.

## Decision

What was decided, stated so that a reader can check code against it.

## Alternatives considered

Each option that was seriously considered and why it was not chosen.

## Consequences

What follows from the decision, good and bad: rules the code must now follow, what becomes easier
or harder, what has to be revisited and when.
